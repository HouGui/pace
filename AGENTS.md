# Working on PACE

- Read `README.md`, `CONTRIBUTING.md` and the document owning the change.
- Keep changes focused; follow the existing architecture and pinned dependencies.
- Run the relevant checks from `docs/development.md`. Record actual test evidence and limitations only in `docs/verification.md`.
- Use synthetic fixtures. Never commit credentials, private data, signing keys, device dumps or local build output.
- Commit, push, publish, flash hardware or provision eFuses only when explicitly requested. Never weaken security checks to make a test pass.
