1 · Home Wi-Fi Saved private fields stay hidden. Leave them blank to keep them, or enter a replacement. A new network name requires its password or the open-network option.
2 · Calendar
Create your adapter using the project's calendar guide first. Never paste your email account password here. When changing the adapter address or source, enter its pairing secret again.
3 · Display English and German controls are available. Latin letters, umlauts and ß are supported; other unsupported characters are reported on screen. An optional second calendar (for example birthdays) is selected in your adapter. Main appointments stay first; the second calendar uses this accent and its own label.
Category colors (optional)

4 · Outdoor temperature (optional) Enter the coordinates in separate fields: for example latitude 48.1234 and longitude 8.5678. Use a decimal point (.), not a decimal comma. Latitude: -90 to 90; longitude: -180 to 180. Negative values mean south or west. Replace the example with your own location; the label alone does not select the weather location. Coordinates and the device IP are sent to Open-Meteo. Its free service is for non-commercial use. Weather: Open-Meteo.
5 · Firmware updates (optional) File uploads work with or without an HTTPS update source. No hosting account is required.
6 · Traffic (optional) Calendar remains the home screen. Open routing needs no API key or billing. Car times exclude live congestion; transit coverage and live delays depend on local data. Reopen Traffic to request fresh estimates.

For both start and destination, enter latitude, longitude, for example 48.1234, 8.5678. Use a decimal point (.) and one comma between the numbers. Latitude: -90 to 90; longitude: -180 to 180. Diagnostics and recovery

Install a signed firmware build once by USB. Later, select a file signed with the same key. Keep USB power connected; the device checks the file before restarting.

Signed firmware is required. File uploads work without hosting; HTTPS updates use an optional manifest URL.

Hold Settings on the device to reopen setup. This network closes after 15 minutes without activity. Typing and tapping keep it open.
